# Security Policy

## Supported Versions

Security fixes are provided for versions that are actively maintained by JuliHyro Studios.

The availability of security updates depends on the maintenance status of each release. Please check the repository's release notes and version history for details.

## Reporting a Vulnerability

If you discover a potential security vulnerability in **CMD Interactive Library**, please report it through the repository's [GitHub Issues](https://github.com/JuliHyro-Studios/cmd.interactive/issues).

When submitting a report, please include:

- A clear description of the vulnerability.
- The steps required to reproduce the issue.
- The potential impact of the vulnerability.
- Relevant code snippets, logs, or proof-of-concept examples, if available.

**For confidential security vulnerabilities, please contact us directly at [hycoremc907@gmail.com](mailto:hycoremc907@gmail.com)** instead of disclosing technical details publicly.

Please do not include passwords, access tokens, private keys, personal information, or other sensitive data in public issues.

## What Happens Next

The maintainers will review the report, assess its severity and potential impact, and determine the appropriate response.

Depending on the findings, the response may include:

- Confirming and documenting the vulnerability.
- Developing and testing a fix.
- Publishing a security update or patched release.
- Providing mitigation guidance when an immediate fix is not available.

Response and resolution times may vary depending on the severity, complexity, and available maintenance resources.

## Scope

This policy covers security vulnerabilities directly affecting CMD Interactive Library and its officially maintained components.

Issues unrelated to security should be reported through the repository's regular issue-tracking process.

## Responsible Disclosure

Please allow the maintainers a reasonable opportunity to investigate and address a reported vulnerability before publicly disclosing technical details that could enable exploitation.

This policy does not prohibit good-faith security research conducted responsibly and within applicable laws.

## Policy Updates

JuliHyro Studios may update this policy as the project and its security practices evolve.
