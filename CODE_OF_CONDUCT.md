# Code of Conduct

## Our Pledge

JuliHyro Studios is committed to maintaining a respectful, inclusive, and professional environment for everyone participating in its projects.

All contributors, maintainers, and community members are expected to treat one another with respect, regardless of their background, experience level, or personal characteristics.

## Our Standards

Examples of expected behavior include:

- Communicating respectfully and professionally.
- Providing constructive feedback and accepting criticism in good faith.
- Respecting different opinions and technical approaches.
- Keeping discussions focused on project goals, code, documentation, and technical matters.
- Giving appropriate credit to other contributors.

Unacceptable behavior includes:

- Harassment, discrimination, intimidation, or personal attacks.
- Insults, threats, or deliberately humiliating other participants.
- Publishing another person's private information without permission.
- Trolling, deliberately disrupting discussions, or repeatedly derailing technical conversations.
- Any other behavior that creates a hostile or abusive environment.

## Scope

This Code of Conduct applies to all official JuliHyro Studios project spaces, including:

- GitHub repositories, issues, and pull requests.
- GitHub Discussions, where enabled.
- Official community channels and project-related communication spaces.
- Other spaces where an individual officially represents JuliHyro Studios or one of its projects.

## Reporting

If you encounter behavior that violates this Code of Conduct, report it through the **Issues** section of the relevant GitHub repository:

https://github.com/JuliHyro-Studios/cmd.interactive/issues

When submitting a report, include relevant details and links to the incident whenever possible.

Please avoid publishing sensitive personal information or confidential evidence in a public issue. If a report requires confidential handling, contact the repository maintainers through an available private communication channel.

## Enforcement

Project maintainers are responsible for reviewing reports and enforcing this Code of Conduct.

Depending on the severity and frequency of the violation, maintainers may:

1. Issue a warning and request that the behavior stop.
2. Remove inappropriate content.
3. Temporarily restrict participation in project spaces.
4. Permanently restrict participation in project spaces.

Maintainers will consider the circumstances of each incident and aim to respond fairly and proportionately.

## Maintainer Responsibilities

Maintainers are expected to apply these standards consistently, review reported incidents fairly, and take appropriate action when violations occur.

Maintainers are also expected to communicate enforcement decisions when appropriate while respecting the privacy of the people involved.

## Updates

JuliHyro Studios may revise this Code of Conduct as its projects and communities evolve.

By participating in official project spaces, contributors and community members are expected to follow the current version of this Code of Conduct.
